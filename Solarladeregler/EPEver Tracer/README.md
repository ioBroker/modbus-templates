# EPEver Tracer

Register für die Solarladeregler der EPEver-Tracer-Serie. Ausgelesen über einen HF2211S (RS485-zu-Modbus-TCP-Wandler); ein angepasster WiFi1-Adapter funktioniert ebenfalls.
